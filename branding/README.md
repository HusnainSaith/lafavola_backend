# La Favola branding source

This folder is the transferred source-material archive from the former La
Favola workspace. It is intentionally excluded from the Git repository because
it contains original Affinity and PSD files that exceed the 100 MiB per-file
limit of standard Git hosting.

The deployable logo, fonts, and approved web imagery used by the public site
are versioned in `../site`. Keep the original branding archive here locally;
use an explicitly approved asset-storage or Git LFS arrangement before adding
the large editable source files to a remote repository.
